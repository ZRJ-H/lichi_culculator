# 雀魂麻将计分器

一个专为四人麻将设计的本地计分器，风格参考雀魂 (Majsoul)，纯前端实现，无需后端，数据实时持久化到本地。

## 技术栈

| 技术 | 版本 | 用途 |
|---|---|---|
| React | 19 | UI 框架 |
| Vite | 6 | 构建工具 |
| TypeScript | 5.8 | 类型安全 |
| Tailwind CSS | 4 | 样式 |
| Zustand | 5 | 状态管理 + localStorage 持久化 |
| lucide-react | 0.513 | 图标 |

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（访问 http://localhost:5173）
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

## 已实现功能

### 第一阶段：基础界面与状态管理
- **玩家卡片**：4 名玩家，显示姓名、风位徽章、超大字号实时分数（负分红色高亮）
- **立直**：点击扣除 1000 分，顶部立直棒计数 +1；分数不足时弹出提示；已立直后按钮禁用
- **撤销**：支持多步操作完整回滚（快照机制）
- **数据持久化**：所有状态自动保存到 `localStorage`，刷新页面不丢失

### 第二阶段：和牌结算
- **和牌弹窗**：点击底部【和牌】按钮弹出结算面板
- **和牌者 / 放铳者 / 自摸**：单选卡片，显示风位 + 姓名
- **番数选择**：1番 \~ 役満 \~ 6倍役満（共 18 档）
- **符数选择**：20\~110 符（步长 10）+ 25 符（七対子）；番数 ≥ 5 时自动隐藏
- **算符辅助**（折叠面板）：根据底符、自摸加符、听牌型、雀头、面子自动计算并填入符数
- **实时预览**：选择变化时即刻显示每位玩家的点数增减
- **自动对局流转**：亲家和牌→连荘；子家和牌→过荘（风位轮换，本场清零，局数推进）
- **立直棒结算**：赢家自动收取桌上所有立直棒

### 第三阶段：流局结算
- **荒牌平局**：点击玩家卡片切换听牌 / 未听，实时预览罚符，确认后自动结算
- **途中流局**：九种九牌 / 四风连打等，一键触发，不计罚符，本场 +1，立直棒保留
- **自动对局流转**：庄家听牌→连荘（本场 +1）；庄家未听→过荘（风位轮换，本场也 +1 不清零）
- **立直棒保留**：流局后桌面立直棒不结算，留至下一局

### 第四阶段：规则完善与终局判定
- **多倍役満**：支持 2\~6 倍役満（基础点 16000\~48000）
- **算符辅助**：折叠式符数计算器，支持特殊牌型（七対子 / 平和）、底符、自摸加符、听牌型、雀头、面子（中张 / 幺九 × 明刻 / 暗刻 / 明杠 / 暗杠），结果自动进位到 10 的倍数
- **击飞判定（Tobi）**：任意玩家分数 < 0 时立刻触发终局
- **延长战判定**：东风战东4局 / 半庄战南4局过庄后，若最高分 ≥ 30000 则终局；否则继续进入下一圈
- **终局弹窗**：全屏不可关闭，展示 1\~4 名排名与最终分数，提供【重开新局】按钮
- **对局规则切换**：顶栏东風 / 半荘 Toggle，进行中切换前弹出二次确认

### 第五阶段：裁判系统升级（Bug 修复）
- **立直防呆**：立直时算符辅助强制门前清底符，屏蔽明刻 / 明杠选项
- **延长战终局修复**：南入 / 西入阶段任意玩家分数 ≥ 30000 立即终局（含庄家和牌）
- **累计役满封顶**：非显式选择多倍役満时，役种 + 宝牌总番数严格封顶在 13 番

### 第六阶段：大道至简 + 役种速查表
- **番数直接输入**：彻底移除役种标签多选与宝牌计数器，玩家自行心算后直接点击总番数按钮
- **色彩化番数矩阵**：18 档按钮按满贯级别分色，快速定位目标番数
- **役种速查表**：新增 `YakuDictionary` 抽屉组件，按番数分类列出所有常规役种，标注门清 / 副露限制标签

## 算分规则

严格遵循雀魂四人麻将标准规则：

| 条件 | 基础点 |
|---|---|
| 一般（1-4 番） | `符 × 2^(番+2)` |
| 切上満貫（基础点≥2000 / 4番30符 / 3番60符） | 2000 |
| 満貫（5 番） | 2000 |
| 跳満（6-7 番） | 3000 |
| 倍満（8-10 番） | 4000 |
| 三倍満（11-12 番） | 6000 |
| 役満（13 番） | 8000 |
| 2倍役満（14 番） | 16000 |
| 3\~6倍役満（15\~18 番） | 24000\~48000 |

**荣和得点**：亲家 = `ceil₁₀₀(基础点 × 6)`，子家 = `ceil₁₀₀(基础点 × 4)`

**自摸得点**：亲家赢 → 三人各付 `ceil₁₀₀(基础点 × 2)`；子家赢 → 亲付 `×2`，两子各付 `×1`

**本场加符**：荣和放铳者 +300/本场；自摸每人 +100/本场

**流局罚符**（3000点总计）：1人听→+3000/-1000；2人听→各+1500/-1500；3人听→+1000/-3000；0/4人→无

## 项目结构

```
src/
├── main.tsx                 # React 入口
├── index.css                # 全局样式（Tailwind v4）
├── store.ts                 # Zustand 状态 + 所有算分逻辑 + localStorage 持久化
├── App.tsx                  # 主界面（顶栏 / 规则切换 / 玩家卡片 / 底部操作栏）
└── components/
    ├── WinModal.tsx         # 和牌结算弹窗（直接输入总番数、算符辅助、役种速查入口）
    ├── DrawModal.tsx        # 流局结算弹窗
    ├── GameOverModal.tsx    # 终局排名弹窗
    └── YakuDictionary.tsx   # 役种速查表抽屉（按番数分类，标注门清/副露限制）
```
